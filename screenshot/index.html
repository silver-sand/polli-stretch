Progressive Disclosure

Reading level adjusted · 68% fewer words · original restored on demand

Kernel Progressive disclosure hides detail behind an on-demand trigger so the reader controls depth, not the interface.

Context The pattern borrows from Nielsen's 1993 HIG: show only what's needed for the current task, and let each additional layer cost one deliberate action. It keeps first-time readers unblocked while giving experts a path to depth without ever cluttering the default view.

Full · original Progressive disclosure is a design technique for the presentation of complex material which seeks to enhance user performance by reducing the quantity of information displayed in any one screen. It can be contrasted with progressive attention, which refers to a reading pattern where a reader spends attention one chunk at a time, expanding text in place rather than leaving the page to consult another view of it.
